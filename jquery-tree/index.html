💡 使用说明
• 📁 文件夹节点，📄 文件节点
• 从左侧拖拽节点到右侧 → 复制节点（重复名称会❌提示，无法放置）
• 右侧内部拖拽节点 → 移动位置（✅/❌实时提示）
• 双击文件夹 → 展开/折叠子节点
• 鼠标悬浮 → 高亮显示
• 点击节点 → 选中（蓝色高亮），然后可添加子节点或删除
• ➕ 添加节点 → 有选中节点时添加为子节点，否则添加到根目录
• 🗑 删除节点 → 删除选中的节点（含子节点会提示）
• 🔍 搜索 → 自动展开并高亮匹配节点
